ব্যবসা ম্যানেজার — Business ERP
=================================
[এই আপডেটে ঠিক হয়েছে/যোগ হয়েছে:]
- ড্যাশবোর্ড চার্ট (বিক্রয় বনাম ক্রয়, খরচের বিভাজন) এখন সঠিকভাবে দেখাবে
- মোবাইল ভিউতে নেভিগেশন মেনু এখন হ্যামবার্গার (☰) বাটনে লুকানো/খোলা যায়
- বাকি জমা/পরিশোধের জন্য এখন সুন্দর ফর্ম (আগে ব্রাউজারের সাধারণ prompt ছিল),
  ডিফল্টভাবে সম্পূর্ণ বাকিটাই ভরা থাকে
- ক্রয় এন্ট্রিতে এখন প্রতি লাইনে রং ও শেলফ/তাক নম্বর (দুটোই ঐচ্ছিক) দেওয়া যায় —
  একই পণ্যের ভিন্ন রং স্বয়ংক্রিয়ভাবে আলাদা স্টক-লাইন হিসেবে তৈরি/আপডেট হয়
- অফলাইনের জন্য Chart.js ও Firebase SDK এখন সার্ভিস ওয়ার্কারে ক্যাশ হয়

এই ফোল্ডারে যা আছে:
- business-erp.html   → মূল অ্যাপ (এটা খুললেই অ্যাপ চলবে)
- manifest.json       → অ্যাপ ইনস্টলযোগ্য করার জন্য
- sw.js               → সার্ভিস ওয়ার্কার (ইনস্টল + অফলাইন ক্যাশের জন্য)
- icon-192.png, icon-512.png, icon-512-maskable.png → অ্যাপ আইকন

⚠️ গুরুত্বপূর্ণ: এই ৬টা ফাইল সবসময় একই ফোল্ডারে/হোস্টিংয়ে একসাথে রাখতে হবে।

ডিফল্ট লগইন (টেস্টের জন্য):
   ইউজারনেম: admin
   পাসওয়ার্ড: admin123

⚠️ যদি আগে একবার অ্যাপটা ব্যবহার/ইনস্টল করে থাকেন, নতুন sw.js ঠিকভাবে
   লোড করতে ব্রাউজারে হার্ড-রিফ্রেশ করুন (Ctrl+Shift+R / Cmd+Shift+R),
   না হলে পুরনো ক্যাশ থেকে যেতে পারে।

রং/শেলফ দিয়ে ক্রয় এন্ট্রির উদাহরণ:
   "লাক্স সাবান" নামে একটা বেসিক পণ্য আগে থেকে তৈরি করুন (রং/শেলফ খালি রেখে)।
   এরপর ক্রয় এন্ট্রিতে:
     লাইন ১: লাক্স সাবান, পরিমাণ ৩, রং: সাদা, শেলফ: ৪
     লাইন ২: লাক্স সাবান, পরিমাণ ২, রং: গোলাপী, শেলফ: ৩
   সেভ করলে "লাক্স সাবান — সাদা" ও "লাক্স সাবান — গোলাপী" নামে দুটো আলাদা
   স্টক-লাইন নিজে থেকে তৈরি হয়ে যাবে, প্রতিটার নিজস্ব স্টক ও শেলফসহ।
   বিক্রয়ের সময় এই দুটো আলাদাভাবে বাছাই করা যাবে।

কিবোর্ড শর্টকাট:
   - F2 = নতুন বিক্রয় এন্ট্রি, F3 = নতুন ক্রয় এন্ট্রি
   - পণ্যের ঘরে টাইপ করে বাছাই করলেই কার্সর পরিমাণে চলে যায়; Enter = পরের লাইন
   - জমার ঘরে Enter চাপলেই এন্ট্রি সেভ হয়ে যাবে

অফলাইন সম্পর্কে:
   - প্রথমবার চালু করতে ইন্টারনেট লাগবে, এরপর থেকে অফলাইনেও কাজ করবে
   - ইন্টারনেট ফিরলে সব এন্ট্রি স্বয়ংক্রিয়ভাবে সিঙ্ক হয়
   - সাইডবারে অনলাইন/অফলাইন ইন্ডিকেটর দেখাবে
   - ব্যাকআপ রিস্টোর করতে ইন্টারনেট লাগবে

চালু করার আগে Firebase Console-এ নিশ্চিত করুন:
   1. Firestore Database তৈরি করা আছে
   2. Authentication > Sign-in method > Anonymous চালু করা আছে
   3. Firestore > Rules-এ rules বসিয়ে Publish করা আছে (নিচে দেখুন)

      rules_version = '2';
      service cloud.firestore {
        match /databases/{database}/documents {
          match /{document=**} {
            allow read, write: if request.auth != null;
          }
        }
      }

লোকাল টেস্ট করতে (কম্পিউটারে):
   এই ফোল্ডারে টার্মিনাল/CMD খুলে লিখুন:  python -m http.server 8000
   তারপর ব্রাউজারে যান: http://localhost:8000/business-erp.html

Netlify/GitHub Pages-এ আপলোড করতে:
   এই পুরো ফোল্ডারটাই (৬টা ফাইলসহ) আপলোড/ড্র্যাগ-ড্রপ করুন।

লম্বা URL ছোট করতে:
   - Netlify: সাইট ড্যাশবোর্ড > Site settings > Change site name — এতে
     yourbusiness.netlify.app এর মতো ছোট, নিজের পছন্দমতো subdomain পাওয়া যায়
   - GitHub Pages: রিপোজিটরির নাম ঠিক "আপনারইউজারনেম.github.io" রাখলে
     URL হবে https://আপনারইউজারনেম.github.io (কোনো রিপো-নাম যোগ হবে না)
   - দুটোতেই নিজের ডোমেইন (যেমন mybusiness.com) যোগ করাও ফ্রি — শুধু
     ডোমেইনটা কোনো রেজিস্ট্রার থেকে কিনতে হবে
