ব্যবসা ম্যানেজার — Business ERP
=================================
[এই আপডেটে যোগ হয়েছে: অফলাইন-ফার্স্ট মোড, পণ্যের বিস্তারিত তথ্য (ব্র্যান্ড/সাইজ/কালার/শেলফ),
কিবোর্ড-ফ্রেন্ডলি দ্রুত বিক্রয়/ক্রয় এন্ট্রি (F2/F3 শর্টকাট + টাইপ-করে-খোঁজা)]

এই ফোল্ডারে যা আছে:
- business-erp.html   → মূল অ্যাপ (এটা খুললেই অ্যাপ চলবে)
- manifest.json       → অ্যাপ ইনস্টলযোগ্য করার জন্য
- sw.js               → সার্ভিস ওয়ার্কার (ইনস্টল + দ্রুত লোডের জন্য)
- icon-192.png, icon-512.png, icon-512-maskable.png → অ্যাপ আইকন

⚠️ গুরুত্বপূর্ণ: এই ৬টা ফাইল সবসময় একই ফোল্ডারে/হোস্টিংয়ে একসাথে রাখতে হবে।

ডিফল্ট লগইন (টেস্টের জন্য):
   ইউজারনেম: admin
   পাসওয়ার্ড: admin123

অফলাইন সম্পর্কে জরুরি তথ্য:
   - প্রথমবার চালু করার সময় অবশ্যই ইন্টারনেট লাগবে (লগইন ডেটা ডাউনলোডের জন্য)
   - এরপর থেকে ইন্টারনেট ছাড়াও অ্যাপ খোলা, দেখা, নতুন বিক্রয়/ক্রয়/খরচ এন্ট্রি — সবই করা যাবে
   - ইন্টারনেট ফিরলে সব এন্ট্রি স্বয়ংক্রিয়ভাবে সিঙ্ক হয়ে যাবে (সাইডবারে অনলাইন/অফলাইন
     ইন্ডিকেটর দেখাবে)
   - ব্যাকআপ রিস্টোর করতে ইন্টারনেট লাগবে

কিবোর্ড শর্টকাট:
   - F2 = নতুন বিক্রয় এন্ট্রি (বিক্রয় পেজে থাকা অবস্থায়)
   - F3 = নতুন ক্রয় এন্ট্রি (ক্রয় পেজে থাকা অবস্থায়)
   - বিক্রয়/ক্রয় ফর্মে: পণ্যের নাম টাইপ করুন, তালিকা থেকে বাছাই করলেই কার্সর
     পরিমাণ-এ চলে যাবে; Enter চাপলে পরের লাইন যোগ হয়ে আবার পণ্যের ঘরে ফোকাস যাবে
   - সবশেষে জমার ঘরে Enter চাপলেই এন্ট্রি সেভ হয়ে যাবে — মাউস লাগে না

চালু করার আগে নিশ্চিত করুন Firebase Console-এ:
   1. Firestore Database তৈরি করা আছে
   2. Authentication > Sign-in method > Anonymous চালু করা আছে
   3. Firestore > Rules-এ নিচের rules বসিয়ে Publish করা আছে:

      rules_version = '2';
      service cloud.firestore {
        match /databases/{database}/documents {
          match /{document=**} {
            allow read, write: if request.auth != null;
          }
        }
      }

   তারপর ব্রাউজারে যান: http://localhost:8000/business-erp.html
